Guide

使い方

茨むあんさんの歌枠・楽曲を探す、タイムラインをたどる、選曲を作るための歌唱データベースです。

1 範囲を選ぶ

リスナー/配信者モードを切り替えて、見たいデータに絞ります。

2 曲を探す

全曲リスト・ランキング・検索で曲名・アーティスト・ジャンルから探せます。

3 歌枠をたどる

タイムラインから月別に歌枠を確認・再生。セトリをコピーできます。

データ範囲とモード

  • ヘッダーの リスナー/配信者 で閲覧向け・選曲向けの表示を切り替えます。
  • 左端のメニューは折りたたみが標準です。ハンバーガーボタンで展開・折りたたみを切り替えられます。
  • 選曲・セトリ作成向けの 配信者モード は、全曲リスト内の「配信者モードで選曲」ボタンで切り替えます。
  • サイドバー下のプロフィールアイコンから、公式チャンネルや X へのリンクが開きます。

曲を探す

  • / または Ctrl+K でサイト内全検索を開き、曲・アーティスト・配信を横断検索できます。
  • 全曲リスト ではジャンル・タグ・キー・並び替えで詳細な絞り込みができます。
  • 曲を押すと 歌唱回数・キー・初披露日・歌枠履歴 を確認できます。
  • ランキング では今月・先月・直近7日・月別の歌唱回数ランキングを表示します。前月比も確認できます。

ダッシュボード

  • TOP5 楽曲・よく歌われた曲(今月/今年切替)・ジャンル分布・月別歌唱数・配信ヒートマップを一覧できます。
  • 下に進むと 直近の歌枠 と 分析(成長グラフ・曜日分布など)が続きます。

配信タイムライン

  • 配信日・曲数・枠番号などで並び替えができ、日付順のときは 月別グループ で表示されます。
  • 月へ移動 プルダウンで、指定した月のグループへスクロールできます。
  • 各グループをクリックして展開すると、その月の歌枠一覧が表示されます。
  • コピーボタンでその枠のセトリをテキスト形式でクリップボードにコピーできます。
  • 曲名を押すと全曲リストでその曲の詳細が開きます。

動画ビューワー（PC のみ）

  • タイムラインの ▶ ボタンや曲詳細の歌枠履歴から、その場で動画を再生できます。
  • 操作バーで 前へ / 再生・一時停止 / 次へ / 連続再生 / リピート / 栞（保存） が使えます。
  • Space で再生・一時停止、← → で 10秒 巻き戻し・早送り。
  • 歌枠ではセットリストの タイムスタンプ で再生位置を記録。共有バッジ はコミュニティ審査済みのタイムスタンプで、「+ 提案」から投稿できます。
  • 共有 ボタンで現在位置付きリンクをコピー・SNS 共有できます。
  • 戻るとミニプレイヤーで再生を継続。音楽プレイヤーで聴く で画面下バーへ移せます。
  • 再生中も左のメニューから他のタブへ移動できます(再生はミニプレイヤーに引き継がれます)。

音楽プレイヤーバー

  • 画面下のバーで 前へ / 再生・一時停止 / 次へ / 連続再生 / リピート / シャッフル を操作できます。
  • キューアイコン で次に流れる曲の一覧を開き、曲をタップして移動できます。
  • サムネ右上のボタンや 動画で見る からいつでも動画ビューワーへ切り替えられます。

プレイリスト（マイリスト）

  • マイリストを作成し、歌枠と動画を混在させて追加・連続再生できます。
  • タイムライン・ビューワーの 栞ボタン や、まとめて選択して一括追加できます。
  • 行は ドラッグで並び替え。リンクを共有 で他の人とリスト共有、YouTube で連続再生 も可能です。

分析

  • ダッシュボードを下に進むと 分析（持ち曲の成長グラフ・曜日分布・アーティスト別集計など）が続きます。
  • 久しぶりに歌われた曲、1回だけ歌われた曲の一覧も表示します。

曲リクエスト

  • 「リクエスト」タブのフォームから歌ってほしい曲を送れます。曲名・アーティスト・URL などを入力して送信します。
  • 同じ曲が 「みんなのリクエスト」 にすでにある場合は、重ねて送らずにその曲の 「聴きたい」ボタン を押してください。投票数順に並びます。
  • 「聴きたい」はもう一度押すと取り消せます（投票状態はこのブラウザに保存されます）。
  • リクエストを確認すると 「歌える曲」（レパートリー入り）や 「練習中」 のバッジが付きます。バッジが無いものはまだ確認前です。
  • 自分が送ったリクエストには 「自分の投稿」 バッジと取り消しボタン（×）が出ます。ほかの人が投票した後や、運営が対応を始めた後は取り消せません。
  • 取り消し用のキーはこのブラウザにのみ保存されるため、ブラウザのデータを消したり別の端末から見たりすると自分では取り消せなくなります（その場合はお問い合わせください）。

配信者モード

  • 全曲リストの 「配信者モードで選曲」 ボタンで切り替えると、選曲・セトリ作成向けの機能が追加されます。
  • 全曲リストで候補をセトリに追加して並び替え・コピーができます。
  • 各曲の キー 情報をもとに、配信で使うキーを確認・設定できます。

キーボードショートカット

  • / Ctrl+K — サイト内全検索を開く
  • T — ダーク / ライトテーマ切替
  • ? — このヘルプを開く
  • Esc — 検索・モーダルを閉じる
  • Space — 動画ビューワーで 再生 / 一時停止
  • ← → — 動画ビューワーで 10秒 巻き戻し / 早送り

うまく表示されないとき

  • データ更新直後は数分待ってから再読み込みしてください。
  • 古い表示が残る場合はブラウザのハードリロード（Ctrl+Shift+R）を試してください。
  • 曲名やキーの誤り・不具合はフッターの「お問い合わせ」から連絡できます。
まずは範囲を選べます リスナー/配信者モードを切り替えて表示を絞れます。選曲やセトリ作成は全曲リストの「配信者モードで選曲」から。詳しい使い方はヘッダーの「?」から見られます。
