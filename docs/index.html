Guide

使い方

曲を探す、歌枠をたどる、配信用の選曲を作るための歌唱データベースです。

1 モードを選ぶ

リスナー向けと配信者向けの表示を切り替えます。

2 曲を探す

全曲リスト・ランキング・検索で曲名・アーティスト・ジャンルから探せます。

3 歌枠を見る

タイムラインから歌枠を選んで、その場で動画を再生できます。

データ範囲とモード

  • ヘッダーの茨むあん表示は、このサイトの対象チャンネルです。
  • リスナーモードは閲覧向け、配信者モードは選曲・セトリ作成向けです。
  • Official は公式YouTube・Xへの外部リンクです。

曲を探す

  • / または Ctrl+K でサイト内全検索を開き、曲・アーティスト・配信を横断検索できます。
  • 全曲リストではジャンル・タグ・並び替えで詳細な絞り込みができます。
  • 曲を押すと 歌唱回数・キー・初披露日・歌枠履歴 を確認できます。

歌枠ビューワー

  • タイムラインのサムネイルを押すと、その場で配信動画を再生できます。
  • セットリストの ⏱ メモ で現在の再生位置をタイムスタンプ記録、バッジをタップするとその箇所へジャンプします。
  • 👥 バッジ はコミュニティが提案・審査済みのタイムスタンプです。「+ 提案」で自分のタイムスタンプを投稿できます。
  • プレイヤー下の 連続再生 をONにすると、動画終了後に自動で次の配信へ移動します。
  • 戻るボタンを押すとミニプレイヤーで再生を継続。ミニプレイヤーのタイトルをタップすると配信ビューワーへ戻れます。

プレイリスト

  • プレイリストタブでマイリストを作成し、好きな歌枠を自由に追加・管理できます。
  • タイムラインの各歌枠の ＋ ボタンや、歌枠ビューワー下部からもプレイリストへ追加できます。

ランキング・配信者モード

  • ランキングは今月・先月・直近7日・月別に切り替えられ、前月比も確認できます。
  • 配信者モードでは選曲候補をセトリに追加して並び替え・コピーができます。

キーボードショートカット

  • / Ctrl+K — サイト内全検索を開く
  • T — ダーク/ライトテーマ切替
  • ? — このヘルプを開く
  • Esc — 検索・モーダルを閉じる

うまく表示されないとき

  • データ更新直後は数分待ってから再読み込みしてください。
  • 古い表示が残る場合はブラウザのハードリロードを試してください。
  • 曲名やキーの誤り・不具合はお問い合わせから連絡できます。
表示モードを選べます 閲覧はリスナー、選曲やセトリ作成は配信者モード。詳しい使い方はヘッダーの「?」から見られます。
